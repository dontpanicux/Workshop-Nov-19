# Win-back dashboard workshop deck (Nov 19)

Single-file HTML deck in the Bolt.new workshop theme (Schibsted Grotesk, JetBrains Mono, blue #1488FC). Push this folder to GitHub, then import the repo into Bolt.new and publish.

- Right arrow, Space, or Page Down: next (reveals steps first)
- Left arrow: back
- N: speaker notes
- F: fullscreen
- Each slide has a URL: index.html#13

All prompts are also in prompts.md, which is the link to drop in chat.

## Run locally

    npm run dev

Opens at http://localhost:3000 (set PORT to change it). No dependencies to install.
`npm run build` copies the deck files into dist/ for publishing.

screenshots/ holds a 1600x900 render of every slide plus contact-sheet.png.
